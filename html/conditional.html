What is a Conditional Sentence?

Conditional sentences describe the result of a certain condition. The if clause tells you the condition, and the main clause tells you the result.

Condition (If-clause) "If it rains,"
➔
Result (Main clause) "I will stay home."

There are 4 main types: Zero, First, Second, and Third. Let's explore them.

Type 0

The Zero Conditional

Usage

Used for facts that are generally or always true (scientific facts, general truths, habits).

Structure

If + Present Simple, ... Present Simple

Examples

  • If you heat ice, it melts.
  • If it rains, the grass gets wet.

Type 1

The First Conditional

Usage

Used for real, possible situations in the future. Things that are likely to happen.

Structure

If + Present Simple, ... will + infinitive

Examples

  • If I study hard, I will pass the exam.
  • If it doesn't rain tomorrow, we will go to the beach.

Type 2

The Second Conditional

Usage

Used for imaginary, unlikely, or impossible situations in the present or future.

Structure

If + Past Simple, ... would + infinitive

Examples

  • If I won the lottery, I would buy a house.
    (But I probably won't win)
  • If I were you, I would apologize.
    (Impossible, I am not you)

Timeline: Imaginary Present/Future

Present (Now)

➔
Imagined Result
The situation is not real; it is a hypothetical scenario right now or in the future.
Type 3

The Third Conditional

Usage

Used for imaginary situations in the past. It describes things that didn't happen and their imagined past results (often used for regrets).

Structure

If + Past Perfect, ... would have + past participle

Examples

  • If I had studied harder, I would have passed the exam.
    (Reality: I didn't study hard, so I failed.)
  • If we had left earlier, we wouldn't have missed the train.
    (Reality: We left late, so we missed it.)

Summary Table

Type Usage Time Structure

First (1) Real/Possible future situations Present/Future If + Present, ... will + inf
Second (2) Imaginary/Unlikely situations Present/Future If + Past Simple, ... would + inf
Third (3) Imaginary past (regrets) Past If + Past Perfect, ... would have + p.p.

Tip: You can always swap the order of the clauses!

"If it rains, I will stay home." = "I will stay home if it rains." (Note: no comma needed if 'If' is in the middle).
